# Решения задач по массивам (Java)

Решения задач из курса «Массивы» на informatics.msk.ru. Каждая задача оформлена отдельной программой с функциями: чтение массива, обработка, вывод.

## Запуск

1. Сохраните код задачи в файл `Main.java`.
2. Скомпилируйте: `javac Main.java`
3. Запустите: `java Main`
4. Введите входные данные с клавиатуры или передайте файлом: `java Main < input.txt`

Для сдачи на informatics.msk.ru выберите язык Java и отправьте код как есть. Класс должен называться `Main`.

## Список задач

| № | Название | Идея решения |
|---|----------|--------------|
| 65 | Количество положительных элементов | Один проход, счётчик элементов больше 0 |
| 66 | Количество элементов, больших предыдущего | Сравнение `a[i]` и `a[i - 1]`, цикл с `i = 1` |
| 67 | Есть ли два элемента с одинаковыми знаками | Соседние числа одного знака, если их произведение больше 0 |
| 68 | Количество элементов больших обоих соседей | Проверка только внутренних элементов, от `1` до `n - 2` |
| 69 | Переставить элементы в обратном порядке | Обмен `a[i]` и `a[n - 1 - i]` до середины массива |
| 70 | Переставить соседние элементы | Цикл с шагом 2, обмен пар; последний при нечётном `n` остаётся |
| 71 | Циклический сдвиг вправо | Запомнить последний элемент, сдвинуть остальные с конца, записать его в начало |
| 72 | Максимум в массиве | Начать с `a[0]`, обновлять при встрече большего |
| 73 | Количество различных в монотонном массиве | Новое число появляется, когда `a[i] != a[i - 1]` |
| 1456 | Шеренга | Место Пети = число учеников с ростом не меньше его + 1 |
| 1457 | Двойной переворот | Функция разворота части массива, вызывается дважды |
| 1460 | Суперсдвиг | Три разворота (весь массив, первые `k`, остальные), `k` приводится по модулю `n` |
| 1461 | Шарики | Поиск цепочки из 3+ одинаковых, удаление сдвигом, повтор до отсутствия цепочек |

## Заметки

- Для чисел до 2³¹−1 по модулю используется `long`, чтобы не было переполнения (особенно в задаче 67 при умножении).
- Там, где запрещён дополнительный массив (69, 1460, 1461), всё делается на месте: обменами и сдвигами внутри исходного массива.
- Вывод чисел идёт через пробел, без пробела в конце строки.
